## 🎯 UCP
Unlabeled target-domain calibration for tabular classifiers under label shift

### 🔍 Overview

This work studies probability calibration for tabular classifiers when class proportions change between the source and target domains and target labels are unavailable.

### ⚙️ Method

The method combines target-prior estimation, prior-shift correction, entropy-constrained temperature scaling, and slice-aware shrinkage to calibrate target-domain predictions.
